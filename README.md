# Рекомендательная система для ритейлера

## Описание проекта

Рекомендательная система, построенная на основе поведенческих данных пользователей ритейлера (просмотры, добавления в корзину, покупки). Система генерирует персонализированные рекомендации товаров для каждого пользователя, что позволяет увеличить конверсию и средний чек.

**Стек:** Python 3.9, implicit (ALS), FastAPI, Docker

---

## Структура данных

Датасет: [Retail Rocket](https://www.kaggle.com/retailrocket/ecommerce-dataset) — логи взаимодействия пользователей с интернет-магазином.

### events.csv

| Поле | Тип | Описание |
|------|-----|----------|
| timestamp | int | Unix timestamp события |
| visitorid | int | Идентификатор пользователя |
| event | string | Тип события: `view`, `addtocart`, `transaction` |
| itemid | int | Идентификатор товара |
| transactionid | float | ID транзакции (только для transaction) |

**Объём:** 2 756 101 строка

### category_tree.csv

Связь `categoryid` → `parent_categoryid`. 1 669 категорий.

### item_properties

Свойства товаров (цена, класс, проект). Два файла, конкатенируются без дублей по ключу.

**Период данных:** 03.05.2015 — 18.09.2015 (137 дней)

**Уникальные сущности:**
- Пользователей: 1 407 580
- Товаров: 417 053

## EDA и preprocessing

### Ключевые находки

- Распределение событий: `view` 96.7%, `addtocart` 2.5%, `transaction` 0.8%
- Воронка конверсии:
  - View → Cart: **2.6%**
  - Cart → Transaction: **32.4%**
  - View → Transaction: **0.84%**
- 460 дубликатов в `events.csv` → удалены

### Подготовка данных

1. Удаление 460 дубликатов из `events.csv`
2. Взвешивание событий:
   - `view` = 1
   - `addtocart` = 3
   - `transaction` = 5
3. Train/Test split: **80%/20%** по времени (граница ~18.08.2015)
   - Train: 03.05.2015 — 17.08.2015
   - Test: 18.08.2015 — 18.09.2015

## Модель

### Алгоритм

**ALS (Alternating Least Squares)** из библиотеки `implicit` — коллаборативная фильтрация, хорошо масштабируется на разреженные матрицы взаимодействий.

**Почему ALS:**
- Работает с разреженными матрицами (плотность 0.0006%)
- Быстрое обучение на GPU/CPU
- Хорошо зарекомендован для e-commerce рекомендаций

### Параметры модели

| Параметр | Значение |
|----------|----------|
| Факторы (factors) | 128 |
| Регуляризация | 0.1 |
| Итерации | 15 |

### Матрица взаимодействий

- Размер: 1 407 580 × 235 061
- Плотность: 0.0006%
- Формат: CSR-матрица

### Метрики

| Метрика | Значение |
|---------|----------|
| HitRate@10 | 0.0063 |
| Recall@10 | 0.0042 |
| MAP@10 | 0.0017 |

> **Примечание:** Метрики кажутся низкими, но это характерно для e-commerce с extremely cold-start и огромным каталогом (417K товаров). Даже одна правильная рекомендация из 10 может принести дополнительный revenue.

### Сохранённые файлы

|------|--------|----------|

## API

FastAPI-сервис на порту 8000.

### Эндпоинты

#### `GET /recommend/{visitorid}`

Возвращает список рекомендаций для пользователя.

**Параметры:**
| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| visitorid | path | — | ID пользователя |
| top_n | query | 10 | Количество рекомендаций |

**Ответ:**
```json
{
  "visitorid": 12345,
  "recommendations": [101, 202, 303, ...]
}
```

#### `GET /stats`

Статистика работы сервиса (количество запросов, среднее время ответа).

**Ответ:**
```json
{
  "total_requests": 150,
  "avg_response_time_ms": 45.2
}
```

#### `GET /health`

Healthcheck. Возвращает `{"status": "ok"}`.

## Метрики и результаты

### Итоговые метрики на test-наборе

| Метрика | Значение | Интерпретация |
|---------|----------|---------------|
| HitRate@10 | 0.63% | В 0.63% случаев хотя бы 1 из 10 рекомендаций релевантен |
| Recall@10 | 0.42% | Модель находит 0.42% релевантных товаров из всех возможных |
| MAP@10 | 0.17% | Средняя точность рекомендаций |

### Сравнение с baselines

| Подход | HitRate@10 |
||--------|------------|
| Случайные рекомендации | ~0.00005% |
| Top-N (популярные товары) | ~0.003% |
| **ALS (наша модель)** | **0.63%** |

> Модель превосходит случайные рекомендации в **12 600 раз** и популярные товары в **210 раз**.
